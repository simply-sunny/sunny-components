Sunny Components is a source-first React and TypeScript component library for focused technical products. It provides accessible actions, inputs, display elements, feedback, navigation, overlays, semantic design tokens, and an animated number component.

Use the package exports for ESM, CommonJS, TypeScript declarations, styles, and tokens, or run the included CLI to copy the component source into your application. React and React DOM are peer dependencies; Radix primitives and Lucide icons support the interactive components.

Run `npm ci` and `npm test -- --run` to verify the library. Run `npm pack` to build and inspect the distributable package. The code is MIT licensed; the half-sun icon is licensed under CC BY 4.0.
