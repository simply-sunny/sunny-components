# Sunny Components Direction Contract

**FORM seed key:** `93b3b341`

## FORM

A familiar, polished component-documentation library: persistent catalog, compact global bar, wide reading canvas, and live examples before implementation detail. The user explicitly selected the canonical plain component-library composition and replaced its reference green with icy blue.

## TYPE

DM Sans carries interface hierarchy with a restrained weight and scale range. IBM Plex Mono is reserved for source, measurements, and technical labels. Headings carry their own meaning without eyebrows or decorative numbering.

## MATERIAL

Flat near-black and soft-white surfaces, fine neutral borders, one level of enclosure, and soft offset shadows only for overlays. No gradients, decorative glass, or ornamental icon tiles.

## GROUND

A subtle construction grid connects the gallery to Simply Sunny and Silk-S1. Icy blue marks focus, selection, active navigation, links, and small status signals. The grid is a pinned brand commitment, not a generic decoration.

## MOTION

Quiet 180ms state feedback with content visible by default and a complete reduced-motion override. Motion communicates interaction state; it never becomes a page entrance spectacle.
